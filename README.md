# Sales Data Analysis Using Power BI
## Project Overview
-This project focuses on cleaning, transforming, and analyzing sales data using Power BI. The dataset, SalesData_1000Rows_WithIssues.csv, contains customer order information along with several data quality issues such as missing values, duplicate entries, and inconsistent date formats.
-The objective is to clean the raw dataset and transform it into meaningful insights through an interactive Power BI dashboard.

## Project Objective
-Clean and prepare the raw sales dataset for analysis.
-Identify and handle missing values.
-Detect and remove duplicate entries.
-Standardize inconsistent date formats.
-Analyze customer orders, sales, profit, products, and costs.
-Create meaningful KPIs to measure business performance.
-Build an interactive Power BI dashboard for data visualization and analysis.

## Tools Used
-Power BI
-Power Query – Data cleaning and transformation
-DAX – KPI and measure creation
-Power BI Visualizations – Data analysis and dashboard development

## Data Cleaning & Transformation
The following data preparation activities were performed:
-Identified and handled missing values.
-Detected and removed duplicate records.
-Standardized inconsistent date formats.
-Corrected data types where required.
-Checked the dataset for inconsistencies.
-Prepared the cleaned data for analysis in Power BI.
