# Sales Data Analysis Using Power BI

## Project Objective
- Clean and prepare the raw sales dataset for analysis.
- Identify and handle missing values.
- Detect and remove duplicate entries.
- Standardize inconsistent date formats.
- Analyze customer orders, sales, profit, products, and costs.
- Create meaningful KPIs to measure business performance.
- Build an interactive Power BI dashboard for data visualization and analysis.

## Tools Used
- Power BI
- Power Query – Data cleaning and transformation
- DAX – KPI and measure creation
- Power BI Visualizations – Data analysis and dashboard development

## Data Cleaning & Transformation
The following data preparation activities were performed:
- Identified and handled missing values.
- Detected and removed duplicate records.
- Standardized inconsistent date formats.
- Corrected data types where required.
- Checked the dataset for inconsistencies.
- Prepared the cleaned data for analysis in Power BI.

## Key insights
- East has the highest order share at 28.57%, while North has the lowest at 22.94%.
- Monitor is the highest-demand product with the largest quantity ordered.
- Smartphone has the lowest quantity ordered among the products.
- Furniture generates higher sales than Electronics.
- Total sales are 89.84M, while total profit is 4.93M, indicating a relatively low profit margin.
- Sales and order volumes show significant fluctuations across years, with several peak and low periods.
- East has highest customers ordered over regions.

## Recommendations
- Maintain sufficient stock of high-demand products like Monitors to avoid stock-outs.
- Improve sales of low-performing products like Smartphones through targeted promotions and pricing.
- Focus on strengthening sales in the North region through region-specific marketing strategies.
- Reduce costs and unnecessary discounts to improve overall profit margins.
- Use seasonal sales trends to optimize inventory and promotional planning.
- Identify high-sales, low-profit products and review their pricing and cost structure.

## Dashboard
- The Power BI dashboard provides an interactive view of sales data analysis using charts,KPIs,slicers etc.
